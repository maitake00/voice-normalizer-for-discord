■ これは何？
  Discord の通話で、人によって声が大きすぎたり小さすぎたりするのを
  自動で揃えるツールです。
  Discord の「ユーザーの音量」(相手を右クリックすると出るスライダー)を、
  あなたの代わりに少しずつ自動で調整します。

  ・通話の音声を録音・保存・送信することはありません
    (パソコンの中で音の大きさを測るだけです)
  ・変わるのは「あなたの側で聞こえる音量」だけです。
    相手の設定や、相手に聞こえるあなたの声は変わりません
  ・Discord の公式ツールではありません。自己責任でお使いください

■ 動作環境
  ・Windows 11 推奨
    (Windows 10 でも、更新を入れていれば多くの場合動きます。
     Discord の音だけを取り出せない PC では、画面に
     「PC 全体の音で測定中」と出ます。その場合はゲームや音楽を
     止めた状態でテストしてください)
  ・Discord のデスクトップアプリ(ブラウザ版の Discord では動きません)


■ 起動のしかた
  1. この zip を好きな場所に展開(解凍)します
     ※ zip の中から直接ダブルクリックせず、必ず展開してから使ってください
  2. VoiceNormalizerForDiscord.exe をダブルクリックします

  ※「Windows によって PC が保護されました」という青い画面が出た場合:
    個人が作った、署名のないソフトのため表示されます。
    [詳細情報] → [実行] を押すと起動できます。


■ 始める前に(最初の 1 回だけ)
  1. このテスト版は、登録されたテスターだけが使えます。
     配布した人と Discord のフレンドになったうえで、あなたの Discord
     ユーザー名を伝えて、テスターに登録してもらってください。
  2. Discord に登録しているメールアドレスに招待メールが届くので、
     メールを開いて承認してください。
     (届かないときは迷惑メールフォルダを確認してください)
  3. ツールを起動すると、Discord の画面に確認ダイアログが出るので
     [認証] を押します。
     (Discord のウィンドウが裏に隠れていると気づきにくいので注意)

  準備はこれだけです。自分で何かを作る必要はありません。

  ※ 登録されていない場合は、画面にそのことが表示されます。
    [自分の Discord アプリを使う] から、自分用の Discord アプリ
    (無料・1〜2 分)を作って使うこともできます(画面が手順を案内します)。


■ 使い方
  ツールを起動したまま、いつもどおりボイスチャンネルで通話するだけです。

  ・メンバーが一人ずつ話すと、その人のカードが
    「声を聞き取り中…」→「少しずつ大きく/小さくしています」
    →「✓ ちょうどいい音量です」 と進みます
  ・話している人のカードは緑の枠になります
  ・自分の声は対象外です(通話に自分ひとりだと何も起きません)
  ・2 人以上が同時に話している間は測定しません
  ・[設定] で「目標の音量」と「揃え方」を変えられます
  ・画面は Windows の表示言語に合わせて日本語か英語になります
    ([設定] の「言語」で切り替えられます)

  おすすめ: Discord の [ユーザー設定] → [音声・ビデオ] → [減衰] を 0% に
  してください。ON のままだと音量を正しく測れません。


■ テストで確認してほしいこと
  1. 画面上部に「音声を受信中」「話し声を検出」が緑で表示されるか
  2. メンバーのカードが「声を聞き取り中…」から進み、音量(%)が変わるか
  3. しばらく話したあと、声の大きさが揃ったと感じるか
     (全体的に大きすぎる/小さすぎる、揃うのが遅い/速い、なども教えてください)


■ 結果の送りかた
  画面の右下にある [ログをコピー] を押すと、動作の記録がコピーされます。
  それをメッセージに貼り付けて、感想と一緒に送ってください。
  画面のスクリーンショットもあると助かります。
  GitHub のアカウントがある人は、上記ページの「Issues」に書いてもらっても構いません。

  ※ ログには、通話にいたメンバーの Discord 上の名前が含まれます。
    気になる場合は名前の部分を消してから送ってください。


■ やめたいとき・削除したいとき
  ・ツールを閉じれば止まります。
    変更された音量は Discord 側にそのまま残るので、
    気になる場合は相手を右クリックして手動で 100% に戻してください
  ・削除するときは、展開したフォルダと、以下のフォルダを削除してください
    (ここにあなたの Client ID などの設定が保存されています)
      %APPDATA%\VoiceNormalizerForDiscord
    ※ エクスプローラーのアドレス欄に上の文字をそのまま貼り付けると開けます
  ・自分用の Discord アプリを作った場合は、Developer Portal から削除できます
